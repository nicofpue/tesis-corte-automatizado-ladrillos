# Electrónica

- **`Esquematicos/PCB_tesis_esquematico_y_PCB.pdf`**: esquemático y PCB exportados a PDF (3 páginas).
- **`PCB/PCB_tesis/`**: proyecto Altium Designer. Abrir `PCB_tesis.PrjPcb`; incluye el esquemático (`Scheq_Tesis.SchDoc`) y la PCB (`PCB_TESIS.PcbDoc`).
- **`PCB/Gerber/PCB_TESIS_Gerber.zip`**: archivos de fabricación (Gerber, taladrado y reporte DRC).
- **`PCB/PCB_Solid.step`**: modelo 3D de la PCB para CAD mecánico.

No se incluyeron el historial automático de Altium (`History/`) ni los registros de cambios (`Project Logs`).
