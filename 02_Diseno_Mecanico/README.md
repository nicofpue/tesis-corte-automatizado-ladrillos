# Diseño mecánico

- **`Planos/PDF/`**: planos por subsistema (Electrónica, Ensamble, Estructura, Sujeción).
- **`Planos/Planos_SolidWorks.zip`**: planos fuente (`.SLDDRW`) y plantilla de rótulo.
- **`Modelos_CAD/CAD_Diseno_Final`**: diseño final. Ensamble principal: `CAD_Cortadora_Ladrillos.SLDASM`.
- **`Modelos_CAD/CAD_Prototipo`**: prototipo de pruebas. Ensamble principal: `Prototipo/Pruebas2/CAD_Cortadora_Ladrillos.SLDASM`.

Los modelos CAD están divididos en partes (`.z01`, `.z02`, …, `.zip`). Para abrirlos, descargue todas las partes en una misma carpeta y descomprima el `.zip` con 7-Zip o WinRAR.

Las simulaciones de SolidWorks no se incluyeron por el límite de tamaño de GitHub.
